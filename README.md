# 🚀 Databricks Sales Analytics Project

## 📊 Project Overview
Full analytics workflow built on Databricks
using real sales data from a bike company.

## 🛠️ Tools Used
- Databricks SQL Editor
- Databricks Dashboards
- AI Genie

## 💡 Key Insights
- 💰 Total Sales: $29.3M
- 👥 Total Customers: 18,484
- 🏆 Top Category: Bikes (96% of sales)
- 📅 Peak Month: December 2013

## 📈 Dashboards Built
1. Exploring Sales Data Dashboard
2. Sales Dashboard
3. Customer Dashboard

## ✅ Skills Demonstrated
- SQL querying and data exploration
- Dashboard design for business users
- AI-powered data interaction using Genie

## 📌 Project Phases
- Phase 1: Data Exploration with SQL
- Phase 2: Exploring Sales Data Dashboard
- Phase 3: Sales & Customer Dashboards
- Phase 4: AI Genie Chat with Sales
